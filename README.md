# Yun Deng — Economics Portfolio

Personal portfolio website built with Next.js and Tailwind CSS, showcasing quantitative economics research projects.

**Live site:** https://econ-portfolio-ff7ngrdfv-louisa328s-projects.vercel.app

---

## Projects

- **Does Higher Occupational AI Exposure Cause Higher Probability of Self-Employment?** — Causal inference using Double Machine Learning (DML)
- **Minimum Wages and Employment** — Card & Krueger (1994) replication with Difference-in-Differences
- **Depression Risk Prediction** — XGBoost and Random Forest on NHANES 2015–2023 data
- **House Price Prediction** — OLS, Ridge, Lasso, and Random Forest on AHS 2023 microdata

## Tech Stack

Next.js · TypeScript · Tailwind CSS · Vercel
